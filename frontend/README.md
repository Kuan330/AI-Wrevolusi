# AI-Wrevolusi Frontend

React + TypeScript + Vite frontend for AI-Wrevolusi.

## Run

```bash
cd frontend
npm install
npm run dev
```

Default URL:

- `http://127.0.0.1:5173`

## Build

```bash
npm run build
npm run preview
```

## API Base URL

Create `frontend/.env` from `.env.example`:

```bash
cp .env.example .env
```

Default value:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
```
