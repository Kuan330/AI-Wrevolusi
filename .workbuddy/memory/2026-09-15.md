### 技术坑（已踩过，别再踩）
- **JS 对象的整数型键按数值升序迭代**，不是插入顺序。`{21:…,1:…}` 上 `Object.values()`
  得到 `[1,21,…]`，会让连线/颜色错位。要用显式数组 + 数据排序得出唯一真源。
- SVG 的 `fill="…"` 是**表现属性**，优先级低于 CSS 类选择器。别同时写同名的 CSS fill。
- 固定行高布局里不要用 px 定死 SVG 尺寸，用 flex 容器 + `width/height:100%` +
  默认 `preserveAspectRatio="xMidYMid meet"` 自适应。
- jsdom 没有 `scrollIntoView`、没有布局；断言几何要用公式自己算，别指望它量。
